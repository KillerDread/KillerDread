## `02 // PROJECT DIVISIONS`

### 🖨️ 3D PRINTING LAB

Diseño y fabricación digital para convertir conceptos en objetos físicos.

- Modificaciones y mejoras para impresoras 3D.
- Piezas funcionales y repuestos personalizados.
- Prototipos, accesorios y soluciones prácticas.
- Diseños y perfiles de impresión documentados.

**Tools:** Ender 3 Pro · CAD · Slicing · 3D Printing

### 🔌 ELECTRONICS & EMBEDDED SYSTEMS

Proyectos que conectan hardware, electrónica y programación.

- Experimentos con Arduino y microcontroladores.
- Automatización de tareas y pequeños sistemas.
- Sensores, actuadores e integración de componentes.
- Reparación y reutilización de dispositivos electrónicos.

**Tools:** Arduino · C/C++ · Sensors · Microcontrollers

### 🤖 AI-POWERED SOFTWARE

Software desarrollado explorando las posibilidades de la inteligencia artificial como herramienta de programación.

- Aplicaciones y utilidades de escritorio.
- Scripts para automatizar tareas.
- Herramientas para makers y técnicos.
- Prototipos, asistentes y experimentos de IA.

**Technologies:** Python · Git · APIs · AI Coding Tools
